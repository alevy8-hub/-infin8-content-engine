# iNFiN8 Content Engine — V0

**Create Once. Distribute iNFiN8. ♾️**

Static prototype built for GitHub Pages.

## What it does
- Paste one source
- Generates 8 platform-oriented draft assets
- Edit each result
- Copy each result
- Export each result as .txt
- Saves source/results locally in the browser
- Mobile-first and GitHub Pages friendly

## Important
This V0 uses temporary deterministic transformation logic in `app.js`.
It is intentionally separated so a real AI generation layer can replace it later.
